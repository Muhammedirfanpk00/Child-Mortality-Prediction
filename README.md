# 👶 Child Mortality Prediction Using Machine Learning

## Project Overview

This project uses Machine Learning techniques to predict child mortality-related outcomes based on relevant healthcare, demographic, and socio-economic factors. The project aims to demonstrate how machine learning can be used to analyze data and support better decision-making.

## Problem Statement

Child mortality is an important public health concern influenced by factors such as healthcare access, socio-economic conditions, nutrition, and living environment. Analyzing these factors using machine learning can help identify patterns and support early decision-making.

## Objectives

- Predict child mortality using machine learning.
- Analyze important factors affecting child mortality.
- Compare different machine learning algorithms.
- Evaluate model performance.
- Provide predictions through a simple user interface.

## Dataset

The dataset used in this project is obtained from Kaggle.

It contains relevant healthcare, demographic, and socio-economic attributes used for predicting child mortality-related outcomes.

## Data Processing Steps

The major steps involved are:

1. Data collection
2. Data cleaning
3. Handling missing values
4. Data preprocessing
5. Exploratory data analysis
6. Feature selection
7. Model training
8. Model evaluation
9. Prediction
